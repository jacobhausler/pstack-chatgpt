# Role map

Keep user settings at these five groups. These labels describe prompt responsibilities; they are not registered agent types.

| Group | Upstream pstack roles |
| --- | --- |
| worker | Code delegates and implementation roles, including `feature`, `refactoring`, `bug-fix`, `perf-issue`, `hillclimb`, `hardest tasks`, and `swarm workers`. |
| investigator | `how explorer` and `why investigators`. |
| reviewer | Judgment-oriented work such as `judgment and prose`, `architect runners`, `interrogate reviewers`, `reflect` review lenses, `arena runners`, and `arena cross-judge`. |
| verifier | Dedicated verification workers or reviewers. Keep these on the worker choice unless the user asks for a separate setting. |
| synthesizer | `how explainer`, `why synthesizer`, and `reflect` synthesizer. |

If one upstream workflow assigns different roles to the same person, route by the work done in that call. Add a separate setting only when it changes a choice the user actually controls.
